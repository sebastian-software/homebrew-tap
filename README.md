# Sebastian Software Homebrew Tap

Homebrew formulae for command-line tools maintained by Sebastian Software.

## Dalo

Install [Dalo](https://dalo.sh), the Git-backed skill manager for AI agents:

```sh
brew install sebastian-software/tap/dalo
```

The formula is updated automatically when a new Dalo release is published.

## mdtheme

Install [mdtheme](https://github.com/sebastian-software/mdtheme), the native
README composer with YAML configuration and reusable Git themes:

```sh
brew install sebastian-software/tap/mdtheme
```

The tap checks for new mdtheme releases every six hours and verifies installation
before updating the formula. Run the **Update mdtheme formula** workflow manually
when an immediate update is needed. No cross-repository publishing token is required.
